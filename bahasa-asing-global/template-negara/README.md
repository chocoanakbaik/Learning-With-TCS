# Template Profil Negara

Salin `profil-negara.template.json` ke direktori negara dengan nama kode ISO 3166-1 alpha-2, misalnya `negara/US/country.json`.

Setelah itu, buat direktori bahasa/komunitas terpisah untuk setiap bahasa yang relevan. Jangan memasukkan semua bahasa suatu negara ke satu daftar kosakata tanpa identitas bahasa dan wilayah yang jelas.

Urutan dokumentasi untuk setiap bahasa/komunitas:

1. Logat dan aksen
2. Cara bicara
3. Bahasa baku
4. Bahasa nonbaku
5. Bahasa umpatan dan kata kasar
6. Bahasa daerah/minoritas

Setiap entri harus menyimpan contoh, konteks, wilayah, sumber, dan status verifikasi. Jika data belum tersedia, biarkan daftar kosong; jangan mengisinya dengan tebakan.
